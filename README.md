# EEG/ERP Signal Processing and Analysis with EEGLAB & ERPLAB

## Overview

This repository contains practical work and analysis workflows developed during an EEG/ERP signal processing training project using MATLAB, EEGLAB, and ERPLAB.

The project focuses on fundamental and advanced EEG processing pipelines, including EEG preprocessing, artifact correction, ICA-based signal cleaning, and event-related potential (ERP) analysis.

The objective was to develop practical skills in preparing EEG datasets, improving signal quality, and interpreting time-locked neural responses in neuroscience research.

---

## Project Objectives

- Understand EEG signal characteristics and frequency-band activity.
- Develop EEG preprocessing workflows for raw electrophysiological data.
- Apply noise reduction and artifact correction techniques.
- Perform ICA-based artifact identification and removal.
- Analyze event-related potentials (ERP) and condition-related neural responses.
- Evaluate EEG/ERP data quality and interpretation limitations.

# Task 02 — EEG Preprocessing Pipeline

## Objectives

Develop a complete EEG preprocessing workflow, including:

- EEG data import and organization
- Channel location assignment using standard electrode systems
- Bad channel detection and interpolation
- Re-referencing and sampling-rate adjustment
- Filtering and artifact rejection

## Methods & Tools

- EEGLAB preprocessing pipeline
- Channel interpolation
- Average referencing
- Signal filtering
- Zapline line-noise removal
- Manual artifact rejection

## Outcome

A cleaned and quality-controlled EEG dataset prepared for further analysis.

# Task 03 — ICA-Based Artifact Correction

## Objectives

Apply Independent Component Analysis (ICA) to separate neural signals from non-neural artifacts.

## Methods

- EEG preprocessing before ICA
- ICA decomposition
- Component evaluation based on:
  - Spatial topography
  - Signal characteristics
  - Artifact patterns
- Removal of artifact-related components
- EEG signal reconstruction

## Outcome

A cleaned EEG dataset with reduced non-neural contamination.
