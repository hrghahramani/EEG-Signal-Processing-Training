# EEG/ERP Signal Processing and Analysis with EEGLAB & ERPLAB

## Overview

This repository contains practical work and analysis workflows developed during an EEG/ERP signal processing training project using MATLAB, EEGLAB, and ERPLAB.

The project focuses on EEG preprocessing, signal enhancement, artifact correction, ICA-based signal cleaning, and event-related potential (ERP) analysis. The objective was to develop practical skills in preparing EEG datasets, improving signal quality, and interpreting time-locked neural responses in neuroscience research.

## Project Objectives

- Understand EEG signals, neural oscillations, and frequency-band characteristics.
- Develop structured EEG preprocessing workflows.
- Apply filtering and artifact correction methods.
- Perform ICA-based artifact identification and removal.
- Analyze event-related potentials (ERP) and condition-related neural responses.
- Evaluate EEG/ERP data quality and interpretation limitations.

## Task 02 — EEG Preprocessing Pipeline

### Objectives

Develop an EEG preprocessing workflow including:

- EEG data import and organization.
- Channel location assignment.
- Bad channel detection and interpolation.
- Re-referencing and sampling-rate adjustment.
- Filtering and artifact rejection.

### Methods

EEGLAB preprocessing workflow, channel interpolation, average reference, signal filtering, line-noise reduction, and artifact rejection.

---

## Task 03 — ICA-Based Artifact Correction

### Objectives

Apply Independent Component Analysis (ICA) to separate neural activity from non-neural artifacts.

### Methods

- ICA decomposition.
- Component evaluation using spatial patterns and signal characteristics.
- Artifact identification and removal.
- EEG signal reconstruction.
