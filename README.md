# EEG Signal Processing Training

## Overview

This repository documents my practical training in EEG signal processing and preprocessing using MATLAB, EEGLAB, and ERPLAB.

The project focuses on developing practical skills in EEG data handling, preprocessing, artifact detection and removal, and basic EEG signal analysis.

## Training Objectives

* Understand fundamental EEG signal-processing concepts
* Practice EEG data import and dataset organization
* Work with channel locations and bad-channel detection
* Apply re-referencing and resampling
* Perform EEG filtering and line-noise removal
* Practice artifact detection and rejection
* Apply and interpret Independent Component Analysis (ICA)
* Develop familiarity with standard EEG preprocessing workflows

## Tools

* MATLAB
* EEGLAB
* ERPLAB

## Training Assignments

### Assignment 01 — EEG Fundamentals & Software Setup

Initial training in EEG fundamentals, MATLAB, and EEGLAB, including a literature-based task on EEG frequency bands and their relevance to neurological and psychiatric conditions.

### Assignment 02 — EEG Preprocessing

Practical training in EEG data import, channel-location mapping, bad-channel detection and interpolation, re-referencing, resampling, filtering, and line-noise removal.

### Assignment 03 — Independent Component Analysis (ICA)

Practical training in ICA-based EEG artifact identification and rejection, including interpretation of component characteristics and topographical patterns.

### Upcoming Assignments

Additional assignments will be added as the training progresses.
