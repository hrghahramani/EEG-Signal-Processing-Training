# Assignment 01 — EEG Fundamentals & Software Setup

## Overview

This assignment focused on developing foundational knowledge of EEG signals, frequency bands, and basic EEG research concepts, alongside initial setup and familiarization with MATLAB and EEGLAB.

## Objectives

* Review fundamental EEG concepts
* Understand major EEG frequency bands
* Explore the relationship between EEG activity and neurological and psychiatric conditions
* Set up MATLAB and EEGLAB
* Become familiar with the basic EEGLAB environment and workflow

## Tools

* EEGLAB
